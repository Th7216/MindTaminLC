MindTamin Lesson Course — PWA

Cara pasang: upload semua file ke hosting HTTPS, buka index.html, lalu pilih Pasang Aplikasi/Add to Home Screen.
Catatan: data aplikasi saat ini masih tersimpan lokal di perangkat/browser (localStorage + IndexedDB). Untuk sinkronisasi Admin dan orang tua di perangkat berbeda diperlukan database online/backend seperti Firebase atau Supabase.
Fitur baru: Testimoni (tambah, rating, tampil/sembunyikan, hapus) dan tampilan testimoni di halaman pendaftaran publik.
